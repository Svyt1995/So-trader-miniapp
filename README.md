# AI Trader Mini App (Telegram)

Статичная версия мини-приложения для Telegram, повторяющая текущий макет дашборда трейдера. Собрана как одностраничный HTML (без сборщиков), чтобы можно было мгновенно выложить на GitHub Pages и подключить к боту.

## Функциональность

- Вёрстка повторяет последний утверждённый макет (русская локализация, блоки счёта, ИИ-советника, активных/последних сделок, график equity).
- Включён Telegram WebApp SDK (`https://telegram.org/js/telegram-web-app.js`) — при открытии мини-приложение расширяет экран и выставляет фирменные цвета.
- Таблица и карточки заполняются mock-данными, разбиты по режимам (Day, Swing, Scalper); переключение вкладок работает на чистом JS.
- График equity построен на Chart.js 4.x.

## Быстрый запуск локально

```bash
python3 -m http.server --directory . 8080
# затем открыть http://localhost:8080/index.html
```

## Публикация на GitHub Pages

1. Создать приватный или публичный репозиторий, скопировать содержимое `miniapp/` (index.html, README).
2. Включить GitHub Pages (Branch: `main`, Folder: `/`).
3. В настройках бота `/setdomain` указать выданный GitHub Pages URL.
4. `/setmenubutton` (или Web App кнопку в клавиатуре) привязать к URL мини-приложения.
